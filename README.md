# chance

Multi-source randomness studio (web console) for exploring constrained chance in design and systems work.

**Who it is for:** operators and designers who want auditable multi-source randomness, not a single `Math.random` toy.

**What you get:** a Rust-backed web console for multi-source randomness experiments.

## Quick start

```bash
git clone https://github.com/simongonzalezdc/chance.git
cd chance
# build/run via Cargo and the in-tree web console instructions
cargo build
```
